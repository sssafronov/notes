# Notes Project

Проект для ведения заметок.

## Описание

Этот проект предназначен для создания и управления заметками.

## Структура проекта

- `notes/` - папка с заметками
- `templates/` - шаблоны для заметок
- `config/` - конфигурационные файлы

## Использование

Добавьте свои заметки в папку `notes/` и используйте Git для синхронизации с удаленным репозиторием.

## Git команды

```bash
# Добавить изменения
git add .

# Сделать коммит
git commit -m "Описание изменений"

# Отправить изменения на сервер
git push origin main

# Получить изменения с сервера
git pull origin main
```
